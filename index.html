Principais comandos do Git

Um guia rápido para controlar e compartilhar seus projetos.

Substitua os valores entre < > pelas informações do seu projeto.

Configuração

git config --global user.name "Seu Nome"Define seu nome de usuário.
git config --global user.email "email@exemplo.com"Define seu e-mail.
git config --listExibe as configurações atuais.

Repositório

git initCria um repositório Git local.
git clone <url>Baixa um repositório remoto.
git statusMostra o estado dos arquivos.

Alterações

git add <arquivo>Adiciona um arquivo à área de preparação.
git add .Adiciona todas as alterações.
git commit -m "mensagem"Registra as alterações.
git diffVisualiza alterações ainda não preparadas.

Histórico

git log --onelineLista os commits de forma resumida.
git show <commit>Exibe detalhes de um commit.
git blame <arquivo>Mostra quem alterou cada linha.

Branches

git branchLista as branches locais.
git switch -c <nome>Cria e acessa uma nova branch.
git switch <nome>Acessa uma branch existente.
git merge <branch>Integra uma branch à atual.

Repositório remoto

git remote -vLista os repositórios remotos.
git pullBaixa e integra alterações remotas.
git push -u origin <branch>Envia commits para o remoto.

Desfazer alterações

git restore <arquivo>Descarta alterações não commitadas.
git reset HEAD <arquivo>Remove um arquivo da área de preparação.
git revert <commit>Cria um commit que desfaz outro commit.

Guia rápido de Git

Consulte git help <comando> para obter mais detalhes.

Controle, colabore e compartilhe seus projetos.
